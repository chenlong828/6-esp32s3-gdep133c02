## 4. 驱动要点（决定开发工作量）

1. **双 IC 分屏**：屏内两颗驱动 IC 各控左右一半，除公用命令（初始化、刷新）外，同一时刻只能拉低一个 CS。送图必须把 1600×1200 的图**切成左右两张**分别传输，且按"横向 X 轴扫完一行再换行"，切错就整体错位（官方手册 4.5 节明确警告）。
2. **数据格式 4bpp**：每字节 2 像素，每种颜色一个 nibble 码——黑 0x00、白 0x11、黄 0x22、红 0x33、蓝 0x55、绿 0x66。整屏 ≈ 960 KB/帧，MCU 需 ≥1 MB 缓冲或分块流式发送。
3. **QSPI 帧格式**：硬件具备四线（SI0–SI3 全引出），但**两份官方示例实际都只跑单线 SPI**——13.3" 参考设计用 8-bit 命令相位、无 D/C 引脚、10 MHz；7.09" 整理版用 D/C + 20 MHz。QSPI 四线属于"能用但官方没开"的能力，实测刷新耗时瓶颈在波形（12 s）而非传输（960 KB @10 MHz ≈ 0.77 s）。详见 `analysis.md`。
4. **长初始化序列**：AN_TM、CMD66、PSR、CDI、TCON、AGID、PWS、CCSET、TRES、PWR、EN_BUF、BTST_P/N、BUCK_BOOST_VDDN、TFT_VCOM_POWER、PON、DRF、POF 等 20 余条私有命令，顺序错则不出图或花屏；这些参数与波形强绑定，不可随意改动。
5. **必须做抖动（dithering）**：RGB 图不能直接显示，需 Floyd–Steinberg / Atkinson / Stucki / Jarvis-Judice-Ninke 等算法降到 6 色散点图，再取模成数组。官方给了三套工具（见 §6）。
6. **温度补偿**：规格书留了 TSCL/TSDA（I²C 温度传感器）引脚，佳显适配板另加 TCN75A；但官方 ESP32 示例代码是固定 25 ℃ 参数，宽温场景要自行按温度切波形档位。
7. **残影/粘屏**：必须 ≥每 24 h 刷新一次（官方建议中间插"干净图"），电池方案最长 72 h；长期不刷新会产生不可逆残影；出货/存储一律全白。
8. **省电**：不刷新时必须进 deep sleep 或断电——长时间高压保持会损伤膜片且不可修复。

## 5. 机械与可靠性设计须知（摘自 E6 Design Notice，25 页）

- **FPC**：贴在前表面，禁止向上弯折；弯曲半径 1.0–1.5 mm（R > 0.5 mm），背面沿 TFT 边缘有 UV 胶。
- **背板 PCB**：厚度 < 0.45 mm，FPC 比 PCB 短 1 mm。
- **边框**：可视区边框相对 VA 边缘偏移 0.3–0.5 mm，且两侧都要小于 AA 区。
- **盖板**：大尺寸建议加 AG 防眩光；**不可户外**——膜片对 UV 极敏感，若必须见光，盖板 UV 阻隔须 <1%（320–380 nm），并严格控制工作温度。
- **EMC**：屏与主板连接支架要接地；VDD 加滤波电容/磁珠；刷新时 EMI 可能干扰显示，建议早期做整机干扰验证。
- **功耗测试**：规格书的"典型功耗"只覆盖相邻像素同色的场景，抖动/棋盘图属"最大功耗"，系统要按最大功耗设计。
- **可靠性**：高温 60 ℃/240 h、低温 −25 ℃/240 h、40 ℃/90 %RH 240 h、冷热冲击 50 cycle、ESD ±200 V（MM）等，判据为无显示功能 NG。

| 固件 | 一个型号一种固定固件：**USB / SD / WIFI / CH（固定图演示）**，互不通用 |
| 开发环境 | ESP-IDF（手册用 5.5.2）/ Arduino IDE |
| 尺寸 | 98.3 × 69.2 mm |

### 6.2 三种刷图方式

1. **USB 上位机**：`Spectra 6_Image_Tool.exe` → 连 COM → 勾选 13.3 + Flash → LOAD 抖动好的 1200×1600 图 → WRITE → Send To EPD（存 Image1–15）。
2. **SD 卡离线**：在线工具 <https://www.e-paper-display.com/bmp.html> 选尺寸/抖动算法/间隔 → 生成 BIN → 拷入 SD 卡 → 上电按设定间隔轮播，其余时间休眠。
3. **WiFi/手机**：板子自建热点 `NeoFrame`（密码 123456789）→ 192.168.4.1 网页上传，或装 NeoFrame App（iOS/Android，APK 已在 `docs/`）配对，可切实时/轮播模式。

| 工具 | 形态 | 用途 |
|---|---|---|
| 在线 BMP 工具 | 网页 | 选型号→抖动→导出 BIN，配合 SD 卡方案 |

## 9. 风险与待确认

1. **规格书自相矛盾处**：分辨率写 1200(H)×1600(V)，产品页与官网参数表写 1600×1200；接口章节只列了 3/4-wire SPI，未写 QSPI 时序（QSPI 实际靠参考代码）。下单前向 FAE 要 QSPI 时序图与最新版规格书（当前版本 1.0 / 2024-05-30）。
2. **刷新时间口径**：佳显 12 s、微雪 19 s，同为 Spectra 6 膜片；差异大概率来自波形/测试图案/接口模式，不要直接当性能差。
3. **无局刷**：E6 不支持局部刷新，任何"时钟/翻页动画"类需求都不成立。
4. **价格与交期**：官网 price=0、stock=0，实际走询价 + 备货；13.3" 属大尺寸，MOQ 与打样政策需确认。
5. **温区**：0–50 ℃ 是硬约束，户外/冷链/北方冬季场景直接排除（除非自加热+温控）。
6. **长期存储**：必须全白；库存屏若长期显示固定画面会永久残影。
